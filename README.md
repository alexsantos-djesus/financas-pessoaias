# Finanças Pessoais 💰

Sistema simples para gerenciamento de receitas e despesas pessoais, desenvolvido com PHP, MySQL, Bootstrap e jQuery.

## 🎯 Objetivo

Ajudar usuários a controlar suas finanças pessoais de forma prática e segura.

## 🛠️ Tecnologias Utilizadas

- **Frontend:** HTML5, CSS3, Bootstrap 5, jQuery, Chart.js
- **Backend:** PHP puro com PDO
- **Autenticação:** Sessões
- **Banco de Dados:** MySQL
- **AJAX:** Para interatividade sem recarregar a página

## 🧩 Funcionalidades

- Login e registro de usuários
- Adicionar, editar e excluir transações
- Agrupamento por categoria
- Filtros dinâmicos
- Gráficos de análise financeira
- Resumo financeiro (receitas, despesas, saldo total)
